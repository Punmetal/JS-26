## Evidence levels

1. **User says they can do it:** resume/software/role statement.
2. **Visible work supports it:** a specific project and page show the output.
3. **Process or production proof:** source file, playable reel, prototype, research artifact, or breakdown. Add only when actually supplied.

These are evidence states, not numeric skill levels. Do not treat a personal project as weaker solely because it is noncommercial, or claim commercial deployment without evidence.

For application text, confirm which parts Pun designed, created, produced, contributed to, or collaborated on. Use led/directed/owned only when responsibility is established. Retain the draft source filename/page so evidence can be refreshed when a new portfolio arrives.
